# Hallo, Python!

Willkommen in der Welt des **Text-Codes**! Statt Blöcke zu ziehen, schreibst du jetzt Befehle mit der Tastatur. Das klingt schwieriger – ist es aber gar nicht. Python ist eine der beliebtesten Programmiersprachen der Welt, weil sie so gut lesbar ist. Sie steckt in Spielen, Robotern, Webseiten und sogar in Weltraum-Missionen.

## Dein erster Befehl: print

**print** heißt „drucke“ oder „zeige an“. Alles in den Klammern erscheint in der Ausgabe:

```python
print("Hallo, Welt!")
```

```output
Hallo, Welt!
```

Klick bei einem Beispiel auf **Ausprobieren** – dann öffnet es sich im Editor und du kannst es mit **Ausführen** starten.

Wichtig:

- **Text** steht immer in **Anführungszeichen**: `"Hallo"`
- Nach `print` kommen **runde Klammern** `( )`
- Python achtet auf **Groß- und Kleinschreibung**: `Print` funktioniert nicht, nur `print`

## Mehrere Zeilen

Jedes `print` schreibt eine neue Zeile. Python führt die Zeilen **von oben nach unten** aus – genau wie die Blöcke in Scratch:

```python
print("Ich bin Funki.")
print("Ich bin ein Drache.")
print("Ich mag Python!")
```

## Python als Taschenrechner

Zahlen schreibst du **ohne** Anführungszeichen. Dann rechnet Python für dich:

```python
print(3 + 4)
print(10 - 2 * 3)
print(7 / 2)
```

```output
7
4
3.5
```

| Zeichen | Bedeutung | Beispiel | Ergebnis |
|---|---|---|---|
| `+` | plus | `5 + 2` | 7 |
| `-` | minus | `5 - 2` | 3 |
| `*` | mal | `5 * 2` | 10 |
| `/` | geteilt | `5 / 2` | 2.5 |
| `//` | ganzzahlig geteilt | `5 // 2` | 2 |
| `%` | Rest beim Teilen | `5 % 2` | 1 |
| `**` | hoch | `5 ** 2` | 25 |

Wie in Mathe gilt: **Punkt vor Strich**. Mit Klammern kannst du die Reihenfolge ändern: `(10 - 2) * 3`.

> **Achtung:** `"3 + 4"` (mit Anführungszeichen) ist Text – Python schreibt dann einfach `3 + 4` hin, statt zu rechnen!

## Text und Zahlen mischen

Mit einem **Komma** kannst du in `print` mehrere Dinge nacheinander ausgeben. Python setzt automatisch ein Leerzeichen dazwischen:

```python
print("Ein Jahr hat", 365, "Tage.")
print("Eine Stunde hat", 60 * 60, "Sekunden.")
```

## Kommentare

Alles hinter einem `#` ignoriert Python. Das sind **Kommentare** – Notizen für Menschen:

```python
# Das ist ein Kommentar
print("Das wird ausgegeben")  # Das hier nicht
```

## Fehler sind völlig normal!

Jeder Programmierer – wirklich jeder – macht ständig Fehler. Wenn etwas nicht klappt, zeigt dir Funki, in welcher Zeile das Problem steckt und was du tun kannst. Fehler finden und reparieren nennt man **Debugging** – und du wirst darin richtig gut werden!
